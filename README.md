# Storybot

A Telegram bot that makes personalised picture books: a parent sends a photo of their child,
the bot writes a story about them and illustrates every page with the child as the hero, then
delivers a print-ready PDF.

Status: choosing the image model. See [`bakeoff/`](bakeoff/README.md), which runs the same
child, style and story through each candidate model and compares them side by side.
